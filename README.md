# 🚀 Space Shooter – Alien Invasion👽👾

A classic 2D arcade-style space shooter game built using **Python** and **Pygame**.  
Control a spaceship, shoot incoming alien waves, dodge enemy fire, and survive as long as possible.

This project demonstrates core **game development concepts** such as object-oriented programming (OOP), collision detection, event handling, game loops, and state management.

## 🎮 Gameplay Features

- Player-controlled spaceship with smooth movement
- Bullet shooting mechanics
- Multiple alien enemies in wave formations
- Random alien bullet firing
- Collision detection (bullet vs alien, alien vs player)
- Score tracking system
- Game Over condition
- Restart game functionality
- Modular and clean OOP-based file structure

---

## 🕹️ Controls

| Key | Action |
|---|---|
| ← / → | Move spaceship |
| Space | Shoot bullets |
| R | Restart game (after Game Over) |
| Close Window | Quit game |

## 📂 Project Structure

```
Space-Shooter-Alien-Invasion/
│
├── main.py # Main game loop and logic
├── settings.py # Game constants and configurations
├── player.py # Player spaceship class
├── bullet.py # Player bullet logic
├── alien.py # Alien enemy logic

│
├── sounds/ # (Optional) Sound effects

│
├── pycache/ # Python bytecode cache (ignored in Git)
```

## ▶️ How to Run the Game

### 1️⃣ Clone the Repository
```
git clone https://github.com/your-username/space-shooter-alien-invasion.git
```
2️⃣ Navigate to Project Folder
```
cd space-shooter-alien-invasion
```
3️⃣ Install Dependencies
```
pip install pygame
```
4️⃣ Run the Game
```
python main.py
```
